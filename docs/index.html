01  what it does

Less tab-hunting. More shipping.

Running several agents breaks down fast: one sits blocked in a tab you aren't looking at, and closing the terminal kills the work. corral fixes both.

triage

The one that needs you comes first.

The sidebar sorts agents by what they need: blocked and finished on top, then the busy ones, then the quiet ones, each with how long it has waited. Agents you aren't watching ring the bell and send a desktop notification.

Close the lid. They keep going.

A small background server owns every agent's terminal; the UI just attaches to it. Detach, lose SSH, come back from another machine. If corral itself stops for a reboot or an update, it offers to bring every agent back into its conversation.

archive

Put work away, not out.

Done with an agent for now? ^b a archives it: the process ends, but its folder and conversation are kept, even across restarts. ^b A lists them and brings one back where it left off.

scriptable

Agents can drive it too.

Everything the UI does is also a command, with --json where it helps. Hand a task to an agent from a script, wait until it needs you, then read its screen. Hooks for Claude and Codex let them report their own state.

The CLI →
task.shsh
p=$(corral new -- claude)
corral send "$p" "add input validation" --enter
corral wait "$p" --state blocked --timeout 600
corral read "$p" --lines 30
02  the difference

Tabs were fine for one agent.

Terminal tabs

  • An agent asks for permission in a tab you aren't on, and waits twenty minutes.
  • Closing the window or dropping SSH ends every agent.
  • Finding out what each one is up to means clicking through every tab.

corral

  • Blocked agents rise to the top of the sidebar and ring a bell.
  • A background server keeps them running; reattach from anywhere.
  • One sidebar shows every agent's task, branch and pull request.
03  no wrappers

Your agents, unchanged.

corral opens a normal shell. Start an agent the way you always do and corral notices, reads its screen to tell whether it's working, blocked or done, and tracks it.

claudecodexopencodegeminiampcursor-agentcopilotpidroidgrok

Anything else runs too, as a plain shell. Optional hooks: corral integrate claude, corral integrate codex.

04  the keys

Ctrl-b, then one letter.

Everything you type goes to the focused agent. corral's own commands sit behind one prefix, and the mouse works too.

^b n new shell
^b b jump to the next blocked agent
^b j k next / previous agent
^b s show another alongside
^b o only the focused agent
^b a archive the agent
^b x close the agent
^b d detach, agents keep running
^b ? every key
get started

Open the gate. Let them run.

One command installs corral. Run corral in your project and start an agent the way you normally would.

$ curl -fsSL https://bottercode.github.io/corral/install.sh | sh

or cargo install --git https://github.com/bottercode/corral
