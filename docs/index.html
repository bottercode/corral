corral

A terminal runtime for coding agents.

Install

$ curl -fsSL https://bottercode.github.io/corral/install.sh | sh

macOS and Linux. Then run corral.

What it does

  • Run Claude Code, Codex, opencode and others side by side; they keep running when you close the window or lose SSH.
  • See which agent needs you: blocked and finished agents rise to the top, with a bell when one you aren't watching stops.
  • Give each agent its own git worktree, then review, commit and merge its work without leaving the terminal.
  • After a reboot or an update, bring every agent back into its conversation.
  • Script it all: corral new, send, read, wait, with --json.
